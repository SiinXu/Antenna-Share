# Antenna Share

一个简洁优雅的个人主页生成工具。在这里，你可以创建属于自己的数字名片，展示你的社交媒体链接和个性化内容。

## 🌟 特性

- 🎨 多种精美主题
  - 简约风格
  - 新春特别版
  - 更多主题开发中...
- 🔗 支持多种社交媒体平台
  - Meta
  - X (Twitter)
  - Instagram
  - Github
  - 电报
  - 领英
- 📱 完美适配移动端
- ✨ 流畅的动画效果
- 🔒 无需注册，即时预览

## 🚀 快速开始

访问 [Antenna Share](https://antenna-share.incidental.site/) 开始创建你的个人主页：

1. 填写你的基本信息（名称、简介）
2. 添加你的社交媒体链接
3. 选择喜欢的主题
4. 点击分享按钮获取你的专属链接
